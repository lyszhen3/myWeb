# unicode, UTF-8 介绍

> 简单介绍下unicode UTF-8之间的关系. UTF-16, UTF-32其实也差不多

## unicode

1. 包含所有的文字,符号,表情
2. 比较常用的2个字节即16bit.
3. 最新的unicode 总共有21bit
4. 例如中文"中"字的
   1. unicode为 \u4e2d
   2. 转换为二进制为 :01001110 00101101 有效数据总共15位

## UTF-8

1. 总共有1~4个字节

   | 字节数 | 二进制编码规则 | 编码范围 |
   | ---- | ----------------------------------- | -------------------- |
   | 1字节 | 0xxxxxxx | U+0000 -> U+007F |
   | 2字节 | 110xxxxx 10xxxxxx | U+0080 -> U+07FF |
   | 3字节 | 1110xxxx 10xxxxxx 10xxxxxx | U+0800 -> U+FFFF |
   | 4字节 | 11110xxx 10xxxxxx 10xxxxxx 10xxxxxx | U+10000 -> U+10FFFF |

   汉字"中" unicode=\u4e2d 二进制填充进UTF-8 3字节位数 1110[0100] 10[111000] 10[101101]
